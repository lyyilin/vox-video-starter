# Production workflow

## Editorial package

Create, in order:

1. `topic-brief.md`: scope, audience promise, precise question, answer hypothesis, participants/resources/rules/path/bottleneck/cost/failure where applicable.
2. `research-ledger.md`: claim, status, source, scope, disagreement, and visual evidence.
3. `script.md`: final narration in short visualizable sentences.
4. `storyboard.md`: line-to-visual contract, scenes, layers, motion beats, evidence function, asset list, and risks.

Pause for storyboard approval.

## Technical package

Create `episode.json`, validate cues, build the asset manifest, generate and matte assets, synthesize the complete joined narration once, align with Whisper, and build `resolved-episode.json`.

Use captions to resolve every animation and SFX cue. Preview before final rendering.

## Approval gates

1. Content direction approval before the first topic.
2. Script/storyboard approval before Imagegen.
3. Low-resolution preview approval before final rendering.

Do not combine or skip these gates.
